# 🎲 보드게임 컬렉션 매니저 (Board Game Shelf)

구글 스프레드시트의 보드게임 목록을 실시간으로 읽고, 검색/필터링하며, 새 게임을 추가/수정하고, **BoardGameGeek (BGG)** API를 통해 게임 정보를 자동으로 가져올 수 있는 반응형 모던 정적 웹 애플리케이션입니다.

---

## ✨ 주요 기능

1. **실시간 구글 시트 데이터 연동 (읽기)**
   - 공개된 스프레드시트 CSV(`.../pub?output=csv`)를 브라우저에서 직접 가져와 680여 개의 보드게임을 실시간으로 렌더링합니다.
   - 로컬 캐싱을 통해 접속 속도를 최적화하고 오프라인에서도 열람 가능합니다.
2. **모임 맞춤형 인원수 퀵 필터**
   - 상단의 인원수 버튼(`전체`, `1인`, `2인`, `3인`, `4인`, `5인`, `6인`, `7인+`)을 클릭하면 해당 인원으로 플레이 가능한 게임만 즉시 필터링됩니다.
   - 해당 인원이 **베스트 인원**인 게임은 황금 왕관 뱃지와 함께 강조 표시됩니다.
3. **한글 초성 검색 & 실시간 통합 검색**
   - 게임명, 게임 시스템, 비고, 소유자를 실시간으로 검색합니다.
   - **한글 초성 검색**을 완벽 지원합니다. (예: `ㄱㅇㅇ` ➔ "가이아 프로젝트", `ㄷㅁㄴㅇ` ➔ "도미니언")
4. **다차원 필터 및 정렬**
   - 난이도(입문, 초급/하, 중하, 중, 상), 모임 멤버별 소유자, 게임 시스템(덱빌딩, 일꾼놓기, 트릭테이킹 등) 다중 필터.
   - 이름순(가나다), 난이도순, 인원순 정렬.
5. **카드 뷰 & 테이블 뷰 전환**
   - 시각적인 카드 그리드 뷰와 엑셀처럼 한눈에 대량 확인 가능한 테이블 뷰를 원클릭으로 전환할 수 있습니다.
6. **🎲 "오늘 뭐 하지?" (랜덤 게임 추천)**
   - 현재 모인 인원이나 필터 조건에 부합하는 게임들 중에서 무작위로 하나를 추천해 주는 룰렛 기능이 포함되어 있습니다.
7. **BoardGameGeek (BGG) 연동 자동 완성**
   - 게임 등록 시 **[BGG에서 정보 가져오기]**를 누르면 게임명(영문/한글)으로 BGG를 검색하여 다음 정보를 자동으로 입력해 줍니다:
     - 최소 / 최대 인원
     - BGG 커뮤니티 투표 기반 추천 베스트 인원
     - BGG Weight 난이도 ➔ 시트 난이도(입문~상) 자동 변환
     - 게임 메커니즘 ➔ 한글 시스템(일꾼놓기, 덱빌딩 등) 매핑
     - 원제, BGG 평점, 플레이 시간 비고 기재
8. **쓰기 및 동기화 (Google Apps Script 연동 & CSV 백업)**
   - Google Apps Script 웹 앱을 연동하면 정적 웹에서도 구글 시트에 실시간으로 행을 추가/수정/삭제할 수 있습니다.
   - 연동 전이라도 브라우저 로컬 저장소에 즉시 반영되며 언제든 CSV로 내보내기할 수 있습니다.

## 🚀 실행 방법

### 방법 1: 파일 더블 클릭 (가장 간단)
- `index.html` 파일을 더블 클릭하여 크롬, 사파리, 엣지 등 브라우저에서 바로 열 수 있습니다. (별도 설치/빌드 불필요)

### 방법 2: 로컬 웹 서버 실행
```bash
# Python 내장 서버
python3 -m http.server 8000
# 브라우저에서 http://localhost:8000 접속
```

### 방법 2: Vercel로 배포 (★가장 추천 - 구글 시트 & BGG CORS 100% 자동 해결!)

Vercel에 배포하면 함께 구성된 **서버리스 함수(`/api/sheets`, `/api/bgg`)**가 자동으로 활성화되어, 구글 시트와 BGG API의 **브라우저 CORS 차단 문제가 완전히 해결**되며 실시간으로 최신 데이터가 동기화됩니다.

#### 옵션 A: Vercel CLI로 터미널에서 즉시 배포 (1분 소요)
```bash
cd /Volumes/external_hd/2026_project/java_util/boardgame-web
npx vercel
```
- 화면 안내에 따라 Vercel 로그인 후 엔터(Enter)를 누르면 30초 내로 무료 도메인(`https://boardgame-shelf-xxx.vercel.app`)이 발급됩니다.

#### 옵션 B: GitHub 연동 배포 (지속적인 자동 업데이트)
1. GitHub에서 새 저장소를 생성합니다.
2. 코드를 GitHub에 푸시합니다:
   ```bash
   cd /Volumes/external_hd/2026_project/java_util/boardgame-web
   git init
   git add .
   git commit -m "feat: Board Game Manager with Vercel Serverless"
   git branch -M main
   git remote add origin <GitHub 레포 주소>
   git push -u origin main
   ```
3. [Vercel 대시보드](https://vercel.com)에서 **[Add New...] > [Project]** 클릭.
4. 해당 GitHub 저장소를 선택하고 **[Deploy]**를 누르면 끝!

### 방법 3: GitHub Pages로 무료 배포
1. GitHub 저장소를 생성하고 이 폴더의 파일들을 푸시합니다.
2. 저장소의 `Settings` > `Pages` 메뉴로 이동합니다.
3. `Branch: main`, `Folder: / (root)` 선택 후 `Save`를 누르면 수 분 내에 나만의 전용 웹사이트 주소(`https://<아이디>.github.io/<저장소명>`)가 발급됩니다.

## 📝 구글 시트 실시간 쓰기(추가/수정/삭제) 설정 방법

정적 웹페이지에서 구글 스프레드시트에 직접 데이터를 쓰려면 **Google Apps Script(GAS) 웹 앱**을 1회 설정해야 합니다. (무료, 약 2분 소요)

1. 관리할 구글 스프레드시트를 웹 브라우저로 엽니다.
2. 상단 메뉴에서 **[확장 프로그램] ➔ [Apps Script]**를 클릭합니다.
3. 편집창에 있는 기존 코드를 모두 지우고, 이 프로젝트의 `google-apps-script.js` 파일 전체 내용을 복사하여 붙여넣습니다.
4. 우측 상단의 **[배포] ➔ [새 배포]**를 클릭합니다.
5. 톱니바퀴 아이콘(유형 선택)을 누르고 **[웹 앱]**을 선택합니다.
   - **설명**: `보드게임 관리 웹앱`
   - **다음 사용자 권한으로 실행**: `나(내 계정)`
   - **액세스 권한이 있는 사용자**: **`모든 사용자 (Anyone)`** *(중요: 반드시 모든 사용자로 설정해야 정적 웹에서 요청을 받을 수 있습니다)*
6. **[배포]** 버튼을 누르고 Google 계정 권한 승인을 완료합니다.
7. 발급된 **웹 앱 URL**(`https://script.google.com/macros/s/.../exec`)을 복사합니다.
8. 보드게임 웹페이지를 열고 우측 상단 **[⚙️ 설정]** 아이콘을 클릭한 뒤, **[Google Apps Script 웹 앱 URL]** 입력창에 붙여넣고 [설정 저장]을 누르면 완료됩니다!

## 🎲 BGG (BoardGameGeek) API 안내

- BGG 공식 정책에 따라 2025년 7월부터 XML API2에 등록된 애플리케이션 토큰이 권장됩니다.
- 본 애플리케이션은 브라우저 환경에서 발생할 수 있는 CORS 제약을 방지하기 위해 프록시 폴백을 기본 내장하고 있으며, BGG 개발자 토큰이 있다면 [⚙️ 설정] 모달에 입력하여 사용할 수 있습니다.
- 게임 검색 시 한글 이름뿐만 아니라 원제(영문 이름, 예: `Catan`, `Terraforming Mars`)로 검색하면 더욱 정확한 검색 결과를 얻을 수 있습니다.
